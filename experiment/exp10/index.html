Working with MongoDB using Shell Commands

Aim

To demonstrate database creation, document insertion, querying, updating, indexing, and deletion in a document-oriented NoSQL database using MongoDB Shell (mongosh) commands.

Description

MongoDB is a NoSQL document database. Instead of tables and rows, it stores data as flexible JSON-like BSON documents grouped inside collections. The MongoDB Shell (mongosh) is an interactive JavaScript interface for working with the database.

  • Database & Collection Management: use, createCollection()
  • Create: insertOne(), insertMany()
  • Read: find() with $gte, $or, array matching, projections, countDocuments()
  • Update: updateOne(), updateMany() with $set, $inc, $push
  • Indexing: createIndex() with a unique index
  • Delete: deleteOne(), deleteMany(), drop(), dropDatabase()

Open mongosh and paste the commands below one section at a time. The full list is also in students.js.

Download students.js

1. Database & Collection Management

// List all existing databases on the MongoDB server
show dbs;

// Switch to (or create) database 'universityDB'
use universityDB;

// Confirm current active database
db;

// Create an explicit collection named 'students'
db.createCollection("students");

// Display all collections in current database
show collections;

2. Create Operations (Insertion)

// Insert a single document
db.students.insertOne({
  student_id: 101,
  name: "Alice Smith",
  age: 20,
  major: "Computer Science",
  gpa: 3.8,
  skills: ["Python", "MongoDB"],
  enrollmentDate: new Date("2023-09-01")
});

// Insert multiple documents
db.students.insertMany([
  {
    student_id: 102,
    name: "Bob Jones",
    age: 22,
    major: "Data Science",
    gpa: 3.4,
    skills: ["R", "Python", "SQL"],
    enrollmentDate: new Date("2022-09-01")
  },
  {
    student_id: 103,
    name: "Charlie Brown",
    age: 21,
    major: "Computer Science",
    gpa: 2.8,
    skills: ["Java", "C++"],
    enrollmentDate: new Date("2023-01-15")
  },
  {
    student_id: 104,
    name: "Diana Prince",
    age: 23,
    major: "Cybersecurity",
    gpa: 3.9,
    skills: ["Linux", "Python", "Networking"],
    enrollmentDate: new Date("2021-09-01")
  }
]);

3. Read Operations (Querying)

// Retrieve all documents
db.students.find();

// Exact match filter
db.students.find({ major: "Computer Science" });

// Comparison operator ($gte: greater than or equal to)
db.students.find({ gpa: { $gte: 3.5 } });

// Logical operator ($or) and array value check
db.students.find({
  $or: [
    { major: "Cybersecurity" },
    { skills: "MongoDB" }
  ]
});

// Projection: 1 to include, 0 to exclude
db.students.find({}, { name: 1, gpa: 1, major: 1, _id: 0 });

// Fetch a single document
db.students.findOne({ student_id: 101 });

// Count documents matching a condition
db.students.countDocuments({ major: "Computer Science" });

4. Update Operations

// Update a single document using $set
db.students.updateOne(
  { student_id: 101 },
  { $set: { gpa: 3.9, age: 21 } }
);

// Append to an array field in many documents using $push
db.students.updateMany(
  { major: "Computer Science" },
  { $push: { skills: "Git" } }
);

// Increment a number by 1 using $inc
db.students.updateOne(
  { student_id: 102 },
  { $inc: { age: 1 } }
);

5. Indexing

// Create a unique index on student_id
db.students.createIndex({ student_id: 1 }, { unique: true });

// List all indexes on the collection
db.students.getIndexes();

6. Delete Operations & Cleanup

// Delete a single document
db.students.deleteOne({ student_id: 103 });

// Delete all documents with GPA below 3.0
db.students.deleteMany({ gpa: { $lt: 3.0 } });

// Drop the collection
db.students.drop();

// Drop the current database
db.dropDatabase();
